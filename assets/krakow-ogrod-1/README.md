# Kraków, ogród przydomowy nr 1: ZDJĘCIA realizacji ukończonej
Prawdziwe zdjęcia. Trawnik z rolki, obrzeża z kostki granitowej, rabaty z korą, klon palmowy, bonsai (niwaki), głazy, deska kompozytowa, osłona bambusowa, nawadnianie (widoczne zraszacze).
Dane klienta celowo pominięte. Publikacja nazwiska/adresu tylko za pisemną zgodą.
Do poprawy przed publikacją: 02 ma w kadrze pick-upa, wąż, doniczkę na folii (retusz albo nowe zdjęcie).
