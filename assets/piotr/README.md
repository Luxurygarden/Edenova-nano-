# Piotr: zdjęcia referencyjne
Zdjęcia z domu (tło: biuro, szafa, laptop). **Nie do publikacji bezpośrednio.** Służą jako referencja wyglądu do generowania portretów AI i jako wzór do profesjonalnej sesji.
Stylizacja do zachowania: czarna koszula, czarne spodnie, czarny pasek, ręce w kieszeniach, spokojny półuśmiech.
