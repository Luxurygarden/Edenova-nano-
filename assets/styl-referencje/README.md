# Referencje STYLU (ogrody, przy których Piotr pracował, DE)
**NIE publikować na stronie.** To nie są realizacje Edenovy. Służą tylko jako wzór stylu do generowania nowych obrazów AI.

## Wspólny język tych ogrodów (do promptów)
- Duże naturalne głazy (łupek, granit, piaskowiec) osadzone „na stałe”, nie dekoracyjnie.
- Woda jako centrum: basen organiczny, staw kąpielowy z płyciznami, kamienie-stopnie w wodzie.
- Formowane sosny (niwaki), kule bukszpanu, klony palmowe, azalie i różaneczniki: wpływ japoński.
- Twarde materiały naturalne: trawertyn, drewno egzotyczne (tarasy przy wodzie), żwir z obrzeżem z kostki.
- Ogród wpisany w krajobraz: widok na wzgórza, zieleń jako tło.
- Wieczorem: światło spod kamieni i w korony drzew, ciepłe, punktowe.

## Czego NIE brać z tych zdjęć
Plastikowe białe meble, flaga, węże, skrzynki, worki, biały bus, niebieski turkus basenu (sprzeczny z paletą marki: woda raczej naturalna, zielono-szmaragdowa).
